Shader 学习路线图

后续课程从“能改一个效果”转向“理解普通材质如何接入渲染器”。主线改用 Bevy 的 Material2d / Material3d；FullscreenMaterial 保留为后处理专题，而不是默认教学路径。

路线原则：先建立普通 material 的 GPU 程序模型和资源绑定模型，再扩展到 vertex/compute、Bevy renderer schedule，最后进入复杂效果设计。复杂特效不是先背公式，而是先拆输入、空间、状态、pass、资源生命周期。

阶段 3：Bevy renderer 路径

目标：能解释一个效果从 main world 组件，到 extract、prepare、queue、render graph / render schedule，再到 shader bind group 的路径。

App World component
→ ExtractComponent
→ Render World resource / component
→ prepare bind group / pipeline
→ queue draw item
→ Render schedule executes pass
→ WGSL/WESL shader reads bindings

这一阶段先从 Material2dPlugin 与 MeshMaterial2d 开始，因为它是普通游戏材质的基本路径。之后再回到 fullscreen post-process、自定义 render node、自定义 pipeline、pass ordering。

阶段 4：复杂效果设计方法

效果类型先拆什么可能用到的技术

推荐顺序

  1. 先学 @group/@binding/@location：否则不知道 shader 输入来自哪里。
  2. 再学 Material2d 的 @group(2)：普通材质资源如何进入 shader。
  3. 再学 texture_2d、sampler、textureSample：这是 2D/3D 材质和后处理的共同基础。
  4. 然后补 vertex stage：理解 fragment 输入为什么存在。
  5. 之后进入 Material3d 与 Bevy renderer schedule：理解 Rust 侧如何把资源送到 GPU。
  6. 最后做 fullscreen、compute 和复杂效果：这时已经能判断一个效果需要几个 pass、哪些 buffer、哪些 texture。
依据：W3C WGSL specification · Shader 函数式心智模型
本路线服务于当前目标：阅读并编写游戏效果 shader，而不是系统学习图形学所有分支。
