TextureLoad 与 Blur 速查

像素邻域效果的核心是：把当前 fragment 映射到整数像素坐标，然后读取周围 texel。

textureSample vs textureLoad

函数坐标Sampler主要用途
textureSample(texture, sampler, uv)vec2<f32>，归一化 UV使用过滤和寻址规则贴图、后处理取色、UV 扭曲
textureLoad(texture, pixel, mip)vec2<i32> / vec2<u32>，整数像素不使用精确 texel、blur、卷积、描边、边缘检测

安全像素坐标

let size = vec2<i32>(textureDimensions(source));
let pixel = clamp(vec2<i32>(in.position.xy), vec2<i32>(0), size - vec2<i32>(1));

in.position.xy 是 fragment 的物理 framebuffer 坐标。用 textureDimensions 得到当前 texture 的真实尺寸，再 clamp 防止越界。

3 点 blur helper 模式

fn horizontal_blur3(source: texture_2d<f32>, pixel_pos: vec2<i32>, offset: i32) -> vec4<f32> {
    let size = vec2<i32>(textureDimensions(source));
    let center_pixel = clamp(pixel_pos, vec2<i32>(0), size - vec2<i32>(1));

    let left_pixel = clamp(center_pixel + vec2<i32>(-offset, 0), vec2<i32>(0), size - vec2<i32>(1));
    let right_pixel = clamp(center_pixel + vec2<i32>(offset, 0), vec2<i32>(0), size - vec2<i32>(1));

    return (
        textureLoad(source, left_pixel, 0) +
        textureLoad(source, center_pixel, 0) +
        textureLoad(source, right_pixel, 0)
    ) / 3.0;
}

纵向版本只需要把偏移从 (±offset, 0) 换成 (0, ±offset)。

Mask 限制作用域

final = mix(original_color, effect_color, mask)
let center_color = textureLoad(source_texture, position, 0);
let blur_color = horizontal_blur3(source_texture, position, 8);
var rect_color = mix(center_color, blur_color, spotlight_mask);

不要把 mask 塞进 blur helper。helper 负责“如何模糊”；fragment 负责“在哪里应用”。

十字 blur

let h = horizontal_blur3(source_texture, position, offset);
let v = vertical_blur3(source_texture, position, offset);
let blur_color = (h + v) * 0.5;
读取方向说明
左 / 中 / 右横向 helper 从原图读取
上 / 中 / 下纵向 helper 也从原图读取
最终平均得到十字形扩散，不是二次模糊

Two-pass blur

pass 1: source → horizontal blurred intermediate
pass 2: intermediate → vertical blurred final

真正 two-pass 的关键不是“代码里有 horizontal 和 vertical 两个函数”，而是第二个 pass 的输入必须是第一个 pass 的输出。

方案读取源需要额外 render 结构
单 pass 十字 blur原始 source texture不需要
two-pass separable blur第二 pass 读取中间 texture需要中间 texture 或 ViewTarget ping-pong，以及 pass ordering
