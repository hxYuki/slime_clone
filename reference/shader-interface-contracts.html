Shader 接口契约速查

阅读 WGSL/WESL 时，把 @ 标记看成接口契约，而不是装饰语法。先问：这个标记在约束哪条边界？

@group/@binding: renderer resources → shader
@location: shader stage → shader stage / color target
@builtin: GPU pipeline built-in semantics

三类接口

标记约束边界当前项目例子验证方式
@group(0) @binding(n) Bevy/wgpu bind group layout 与 shader 全局资源 source_texture、texture_sampler、material 改变量名不影响；改不存在的 binding 会报 pipeline layout 错误
@location(n) stage 间自定义输入输出，或 fragment 到 color target uv 从 vertex 传给 fragment；fragment 返回颜色到 @location(0) 输入 location 缺失会报前一阶段未提供；输出 location 错槽可能黑屏
@builtin(name) GPU 图形管线固定语义 @builtin(position) fragment 中读取 in.position.x 可按物理 framebuffer 坐标分色

常见错误与现象

改动现象结论
只改资源变量名，并同步使用点 画面不变 外部资源绑定不按变量名匹配
@binding(2) 改成 @binding(3) Binding is missing from the pipeline layout shader 需要的资源槽必须存在于 pipeline layout
uv 从 @location(0) 改成 @location(1) 前一阶段没有提供输入 vertex 输出和 fragment 输入靠 location 对接
fragment 返回 @location(1) 当前路径黑屏、无报错 颜色没有写到可见 color target 0；输出错槽不一定 validation error
in.position.x < 640.0 分色 分界约在左 1/4 position 是物理 framebuffer 坐标，受 DPI/scale factor 影响

position 与 uv 的选择

要表达优先使用原因
屏幕左右半、圆形 mask、归一化效果空间in.uv范围稳定是 0.0..1.0
固定像素宽度描边、像素级 kernel、真实 render target 尺寸in.position + textureDimensions使用物理像素坐标和真实纹理尺寸
let size = textureDimensions(source_texture);
let half_width = f32(size.x) * 0.5;
调试规则：接口实验完成后要恢复槽位编号：uv 回到 @location(0)，fragment 返回值回到 @location(0)，material uniform 回到 @binding(2)。
