修正 UV 的宽高比

项目窗口是 1280×720。UV 的 x、y 都是 0…1，但屏幕宽度和高度并不相等，因此直接计算 UV 距离会把圆拉宽。

本课胜利条件：能解释为什么宽屏中的 UV 圆会变成椭圆，并写出宽高比修正。

1. 归一化范围相同，不代表物理长度相同

在 1280×720 屏幕上，UV 的 x 方向从 0 到 1 跨越 1280 像素，y 方向只跨越 720 像素。因此 distance(uv, center) 测量的是 UV 空间距离，不是等比例的屏幕距离。

2. 先居中，再缩放 x

let center = vec2<f32>(0.5, 0.5);
var delta = in.uv - center;
delta.x *= material.aspect_ratio; // width / height
let d = length(delta);
aspect_ratio = width / height = 1280 / 720 ≈ 1.7778

必须先减去中心再缩放，否则连圆心位置也会被移动。修正后的 x、y 都以“屏幕高度”为统一长度单位。

3. 哪些效果需要修正？

圆、径向光晕、到点的距离场需要修正。当前 shader 的轴对齐矩形使用独立的 x/y 范围比较，不要求两个轴采用相同长度，所以不需要这种修正。
