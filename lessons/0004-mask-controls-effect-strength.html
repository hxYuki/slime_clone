Mask 控制效果强度

布尔条件只能制造“开或关”的硬边界。把区域判断改造成 0 到 1 的 mask，就能平滑控制颜色变化。

本课胜利条件：能读懂 distance → smoothstep → mix，并写出一个圆形软边 mask。

1. Mask 是一个标量控制信号

mask = 0.0  // 完全采用效果 A
mask = 0.5  // A、B 各占一半
mask = 1.0  // 完全采用效果 B

result = mix(A, B, mask);

函数式地看，mask 把“这个 fragment 在哪里”转换成“这个 fragment 应用多少效果”。

UV 坐标
到中心的距离
0…1 mask
混合颜色

2. 从距离生成圆形软边

let center = vec2<f32>(0.5, 0.5);
let radius = 0.3;
let softness = 0.05;
let d = distance(in.uv, center);

let mask = 1.0 - smoothstep(radius - softness, radius, d);
color.rgb = mix(color.rgb * 0.25, color.rgb, mask);

圆内距离小，mask 接近 1，保留原色；圆外距离大，mask 接近 0，采用暗色。smoothstep 把边缘的一段距离平滑压缩到 0…1。

白色表示 mask = 1，黑色表示 mask = 0。拖动参数观察“范围”和“过渡宽度”是两个独立概念。
