Lesson 0010 · Project Integration

在 Bevy 中加载被 Import 的 Shader

WESL 模块已经能独立编译。现在把它放入真实 asset 目录，并让 Bevy 0.19 的运行时 resolver 能找到它。

本课胜利条件：主 shader 能 import helper asset，Rust 侧显式加载该依赖并用强 handle 保持其存活。

1. 四个环节缺一不可

ShaderRef
指定根 shader
AssetServer
加载依赖模块
Handle
保持 asset 存活
import
解析模块符号

根 shader 已由 FullscreenMaterial::fragment_shader() 引用。额外工作只针对它 import 的 helper。

2. 项目已有可复制模式

保留强 Handle

#[derive(Resource)]
struct CircularMaskShader(
    #[expect(dead_code)]
    Handle<Shader>,
);

加载依赖 Asset

let handle = app
    .world_mut()
    .resource_mut::<AssetServer>()
    .load("shaders/circular_mask.wesl");

app.insert_resource(
    CircularMaskShader(handle),
);

字段看似未读取，但持有它本身就是职责。强 handle 的引用计数保证 shader asset 不会因为没有使用者而被释放。

3. Asset 路径与模块路径

// assets/shaders/region_color_screen_material.wesl
import super::circular_mask::circular_mask;

// Rust AssetServer
.load("shaders/circular_mask.wesl");

两边指向同一个 asset：WESL 使用无扩展名的模块路径，AssetServer 使用相对 assets/ 的文件路径。

本课暂不调用 helper：先验证资源生命周期和模块解析，不改变游戏画面。下一步再同步 uniform 参数并把 mask 接入颜色数据流。
