用时间制作 Shader 动画

动画不是特殊类型的 shader。它只是让输入随时间变化：每一帧重新求值，再沿现有组件与 uniform 管道得到不同颜色。

本课胜利条件：不修改同步系统和 WESL，让标题画面的聚光半径在 0.16..0.28 之间平滑呼吸。

1. 把时间变成 0..1

phase = elapsed_seconds × speed
sin(phase): −1..1
wave = (sin(phase) + 1) × 0.5  →  0..1

sin 提供平滑且周期性的波。加一把范围移到 0..2，再乘 0.5 得到适合插值的 0..1。

2. 用 Wave 选择半径

radius = min + (max − min) × wave

这与 WESL 的 mix(min, max, wave) 是同一个线性插值公式。时间只负责产生 mask；插值负责把它映射到有意义的参数范围。

3. 在标题内容层修改组件

fn animate_screen_spotlight(
    time: Res<Time>,
    mut spotlights: Query<&mut ScreenSpotlight>,
) {
    let phase = time.elapsed_secs() * 2.0;
    let wave = (phase.sin() + 1.0) * 0.5;

    for mut spotlight in &mut spotlights {
        spotlight.radius = 0.16 + (0.28 - 0.16) * wave;
    }
}

把系统注册到 title.rs，并与现有 animated_background 一样加上 run_if(in_state(AppState::Title))。标题内容拥有动画策略；渲染模块保持通用。

4. 为什么使用 Elapsed Time

elapsed_secs() 允许直接计算 radius = f(time)。无论一秒渲染多少帧，相同时刻都对应相同半径。delta_secs() 更适合速度积分：position += velocity × delta。

当前系统在 Update 改组件，已有同步系统在 PostUpdate 读取组件，所以本帧的新半径会在渲染前进入 uniform。
