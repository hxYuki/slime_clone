Import 一个 WESL 模块

把已验证的纯函数和 fragment 入口拆开。入口只负责组织效果，helper 模块只负责可复用计算。

本课胜利条件：两个 WESL 文件通过标准模块路径连接，并作为一个完整 fragment shader 编译。

1. 文件路径就是模块路径

shader_exercises/
├── circular_mask.wesl
└── spotlight_fragment.wesl
// spotlight_fragment.wesl
import super::circular_mask::circular_mask;

super 表示当前模块的父路径，再进入同目录的 circular_mask 模块，最后导入同名函数。模块文件名应使用合法标识符，因此练习用 circular_mask.wesl，而不是以数字开头的存档文件名。

2. Helper 与入口各自负责什么？

circular_mask
位置 → 0…1 mask
→ import →
fragment
调用 helper → 输出颜色

本练习暂时把 mask 同时写入 RGB，以灰度图直接观察函数结果：

let mask = circular_mask(
    uv,
    vec2<f32>(0.5, 0.5),
    0.3,
    0.05,
    16.0 / 9.0,
);
return vec4<f32>(mask, mask, mask, 1.0);
Bevy 0.19 的额外要求：WESL import 负责解析模块符号，但 Bevy 的运行时 resolver 只认识已经加载的 WESL asset。真正接入游戏时，还要通过 AssetServer.load 加载依赖并保留强 handle；下一课处理这一层。
