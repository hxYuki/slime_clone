Lesson 0023 · Radial Distortion

径向波形 UV 扭曲

上一课用 mask 把固定方向偏移限制在聚光区。本课把“向右取色”升级为“沿中心向外取色”，并让已有的 radial_wave 决定哪一圈扭曲最强。

本课胜利条件：把固定 vec2(0.03, 0.0) 替换成径向方向 × 波形强度 × mask，做出类似冲击波/折射圈的局部扭曲。

1. UV 扭曲有三个部分

distortion = direction × amount × gate
部分回答的问题本课写法
direction往哪里取色？从聚光中心指向当前 uv 的径向方向
amount偏移多强？radial_wave(...) 给出的环形波强度 × 0.02
gate哪里允许发生？spotlight_mask

2. 方向和距离要分开

radial_wave 已经用 aspect-corrected 距离决定“哪一圈”。现在还需要一个方向决定“往哪里偏移”。为了宽屏下方向不明显变形，先在 aspect-corrected 空间归一化，再转回 UV 空间。

let delta = in.uv - material.spotlight_center;
let aspect_delta = vec2<f32>(delta.x * material.ratio, delta.y);
let d = length(aspect_delta);
let aspect_dir = aspect_delta / max(d, 0.0001);
let uv_dir = vec2<f32>(aspect_dir.x / material.ratio, aspect_dir.y);

max(d, 0.0001) 是防御中心点：在中心 d = 0 时不让方向计算除以 0。

3. 用波形控制扭曲强度

let ring = radial_wave(
    in.uv,
    material.spotlight_center,
    material.ratio,
    32.0,
    6.0,
    material.elapsed_secs,
);

let distortion = uv_dir * ring * spotlight_mask * 0.02;
let sample_uv = in.uv + distortion;
var rect_color = textureSample(screen_texture, texture_sampler, sample_uv);

这里的 ring 既可以继续给后面的发亮圆环用，也可以给采样扭曲用。这样“视觉高亮”和“取色折射”共享同一套空间波形。

职责边界：uv_dir 决定方向，ring 决定波峰在哪里，spotlight_mask 决定作用域，0.02 决定强度。调试时一次只改其中一个。

实际练习：
  1. 打开 assets/shaders/region_color_screen_material.wesl。
  2. 在 spotlight_mask 后面计算 delta、aspect_delta、d、aspect_dir、uv_dir。
  3. 把 ring = radial_wave(...) 移到第一次 textureSample 之前，供采样扭曲和后续圆环发亮共同使用。
  4. 把当前 sample_uv 改成 in.uv + uv_dir * ring * spotlight_mask * 0.02。
  5. 删除后面重复的 ring 定义。
  6. 运行游戏，观察扭曲是否从固定左移变成沿圆环方向的折射；完成后告诉我“已完成”。
