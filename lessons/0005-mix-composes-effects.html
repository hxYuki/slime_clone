用 Mix 合成效果

mask 只描述“应用多少”。mix 决定在两个候选结果之间如何合成最终颜色。

本课胜利条件：看到 mix(A, B, mask) 时，能立即说出 mask 为 0、1 和中间值时的结果。

1. Mix 就是线性插值

mix(A, B, t) = A × (1 − t) + B × t

t = 0 完全选择 A，t = 1 完全选择 B。中间值按比例混合。A、B 可以是标量，也可以是颜色向量。

mix(A, B, 0.50)

2. 用圆形 Mask 做聚光效果

let original = color;
let dark = vec4<f32>(color.rgb * 0.25, color.a);

// 圆内 mask ≈ 1，圆外 mask ≈ 0
color = mix(dark, original, mask);

圆外选择第一个参数 dark；圆内选择第二个参数 original；软边区域自动得到平滑过渡。完整数据流现在是：

textureSample
  → distance
  → smoothstep
  → mask
  → mix(dark, original, mask)
  → return
