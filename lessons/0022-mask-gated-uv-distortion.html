Lesson 0022 · Masked Distortion

用 Mask 控制 UV 扭曲

上一课的 UV 偏移移动了整张屏幕。真实效果通常不会整屏移动，而是在某个区域内折射、扭曲或错位。这个“区域”仍然用 mask 控制。

本课胜利条件：把全屏 sample_uv = in.uv + offset 改成 sample_uv = in.uv + offset * mask，让偏移只在聚光区域明显发生。

1. 颜色 mask 也能控制采样地址

之前你用 mask 控制 mix 的强度：

let lit_color = mix(darken_color, rect_color, spotlight_mask);

同一个 mask 也可以控制 UV 偏移强度：

let distortion = vec2<f32>(0.03, 0.0) * spotlight_mask;
let sample_uv = in.uv + distortion;
let rect_color = textureSample(screen_texture, texture_sampler, sample_uv);
采样地址 = 原始地址 + 偏移方向 × 作用域 mask

2. 这会产生什么画面

3. 先算 mask，再采样

当前 shader 先采样 rect_color，后算 spotlight_mask。本课需要反过来：因为采样地址要用到 mask。

let wave = sin(material.elapsed_secs * 3.1415926) * 0.06;
let spotlight_mask = circular_mask(
    in.uv,
    material.spotlight_center,
    material.spotlight_radius + wave,
    material.spotlight_softness,
    material.ratio,
);

let distortion = vec2<f32>(0.03, 0.0) * spotlight_mask;
let sample_uv = in.uv + distortion;
var rect_color = textureSample(screen_texture, texture_sampler, sample_uv);
关键边界：mask 用 in.uv 算，因为它描述“当前屏幕位置是否属于效果区域”；texture 用 sample_uv 采样，因为它描述“当前屏幕位置要从哪里取颜色”。这两个 UV 不一定相同。

4. 这是折射效果的基本形状

很多热浪、水面、玻璃、冲击波都可以拆成：

mask 决定哪里发生
direction 决定往哪里取色
amount 决定偏移多大
textureSample 读取偏移后的颜色
