Lesson 0018 · Helper Extraction

抽出效果层 Helper

你已经会把 fragment 拆成命名层。下一步是把稳定的组合模式抽成 helper：fragment 只表达“这里要叠加什么”，helper 负责“怎样叠加”。

本课胜利条件：新增一个 WESL helper asset，主 shader import 并调用它；画面语义保持与上一阶段一致。

1. 先确定 helper 的纯函数契约

add_masked_rgb(source, amount, strength) → mixed_color

这个 helper 不读取 texture，不读取 uniform，不知道 spotlight。它只做一件事：按 strength 把当前颜色混向“RGB 增亮后的目标色”。

// assets/shaders/effect_layers.wesl
fn add_masked_rgb(
    source: vec4<f32>,
    amount: f32,
    strength: f32,
) -> vec4<f32> {
    let target = vec4<f32>(source.rgb + vec3<f32>(amount), source.a);
    return mix(source, target, strength);
}

2. Fragment 只保留业务含义

import super::effect_layers::add_masked_rgb;

// ...
let dark_region = 1.0 - spotlight_mask;
let ring_strength = dark_region * ring;
let ringed_color = add_masked_rgb(lit_color, ring * 0.12, ring_strength);

现在 fragment 里可以直接读出：在暗区里，用圆环强度对 lit_color 做 RGB 增亮。

3. 当前 Bevy fork 会自动加载 import 依赖

// 当前 hxYuki/bevy rev f7d2192...
// Shader loader 会从 import 收集依赖：
// shader.file_dependencies.push(load_context.load(asset_path));

// 因此本项目不再需要手写：
// AssetServer.load("shaders/effect_layers.wesl")
// EffectLayersShader(Handle<Shader>)

WESL import 解决语言层符号；当前项目使用的 Bevy fork 会把 import 到的 shader asset 作为 file_dependencies 存入根 shader，自动维持依赖存活。旧 Bevy 0.19 行为仍可能需要手动加载强 handle。

边界：如果 helper 需要 texture、sampler 或 uniform，那就不是这个纯函数层了。本课 helper 只处理显式参数，便于单独阅读、替换和测试。
抽成 helper 时，最重要的是什么？

在当前 Bevy fork 中，新 helper asset 被 import 后 Rust 侧还需要什么？

实际编码：
  1. 新增 assets/shaders/effect_layers.wesl，写入 add_masked_rgb。
  2. 在 region_color_screen_material.wesl 顶部 import add_masked_rgb。
  3. 把当前的 ring_target 与最终 mix 替换为 add_masked_rgb(lit_color, ring * 0.12, ring_strength)。
  4. 不新增 Rust 侧 shader handle；当前 Bevy fork 应自动加载 import 依赖。
  5. 运行游戏，确认视觉语义不变，并确认没有 import 依赖加载错误；完成后告诉我“已完成”。
