UV 是效果的坐标空间

你已经知道 in.uv 决定“在哪里采”。现在用同一坐标直接构造颜色和区域，这是独立编写 2D 效果的第一步。

本课胜利条件：能根据 UV 条件预测它会选择画面的哪个区域。

1. UV 是约定，不是魔法变量

当前全屏 pass 的 vertex shader 产生 UV，光栅化器把它插值后交给 fragment shader。可见视口采用归一化坐标：

左上 (0, 0)右上 (1, 0) 左下 (0, 1)右下 (1, 1)

uv.x 从左向右增大，uv.y 从上向下增大。因为范围与分辨率无关，同一段效果可以工作在不同窗口尺寸上。

2. 让坐标直接变成颜色

@fragment
fn fragment(in: FullscreenVertexOutput) -> @location(0) vec4<f32> {
    return vec4<f32>(in.uv.x, in.uv.y, 0.0, 1.0);
}

红色通道等于 x，绿色通道等于 y。移动指针，观察同一个 fragment 函数在不同 UV 输入下的输出：

uv = (0.500, 0.500)rgb = (128, 128, 0)

3. 条件就是空间选择器

// 左半屏
if in.uv.x < 0.5 { ... }

// 中央矩形
if in.uv.x >= 0.25 && in.uv.x <= 0.75 &&
   in.uv.y >= 0.25 && in.uv.y <= 0.75 { ... }

项目中的 material.rects[i] 正是在传递 (min_x, min_y, max_x, max_y)。原 shader 的四次比较就是一个“UV 是否在矩形中”的谓词。
