Lesson 0024 · Interface Slots

验证 Shader 接口槽位

上一课读懂了 attribute。本课把它变成可验证的接口模型：改变量名、改 binding、改 location、读 builtin，观察 Bevy/wgpu 的真实反应。

本课胜利条件：能解释为什么改资源变量名不影响画面，改 binding 会触发管线验证错误，改输入 location 会报前一阶段未提供输入，而改 fragment 输出 location 在当前路径下表现为黑屏。

1. 变量名不是资源接口

@group(0) @binding(0) var source_texture: texture_2d<f32>;

var rect_color = textureSample(source_texture, texture_sampler, sample_uv);

把 screen_texture 改成 source_texture 后画面不变，因为资源匹配不看变量名。shader 内部必须使用同一个名字，但 Bevy/GPU 对外只关心 @group(0) @binding(0) 和类型。

2. Binding 数字是资源 ABI

@group(0) @binding(3) var<uniform> material: RegionColorScreenMaterial;

当前 fullscreen material pipeline 只准备了 group 0 的 binding 0/1/2。shader 要 binding 3 时，管线创建失败：

Shader global ResourceBinding { group: 0, binding: 3 } is not available in the pipeline layout
Binding is missing from the pipeline layout

这类错误说明 shader 声明的外部资源接口和 Rust/Bevy 创建的 pipeline layout 不一致。

3. 输入 location 是 stage 之间的槽位

struct FullscreenVertexOutput {
    @builtin(position) position: vec4<f32>,
    @location(1) uv: vec2<f32>,
}

fragment 期待 @location(1) 的 uv，但 Bevy 的 fullscreen vertex shader 实际输出 @location(0)。所以验证错误会指向：管线前一阶段没有提供输入。

vertex output @location(n) → fragment input @location(n)

4. 输出 location 不一定报错

@fragment
fn fragment(in: FullscreenVertexOutput) -> @location(1) vec4<f32> {
    return vec4<f32>(1.0, 0.0, 0.0, 1.0);
}

当前实验中没有报错，而是界面变黑。更准确的解释是：shader 写到了 color output 1，但当前显示路径读取的是 color attachment 0。输出没有进入可见目标。

规则修正：输入 location 缺失通常会直接报 pipeline interface 错误；fragment 输出 location 不匹配可能报错，也可能只是写不到当前显示目标。实际行为取决于 pipeline、后端和目标配置。

5. Builtin position 是物理坐标

if in.position.x < 640.0 {
    return vec4<f32>(1.0, 0.0, 0.0, 1.0);
} else {
    return vec4<f32>(0.0, 0.0, 1.0, 1.0);
}

在你的窗口里，640.0 约在左 1/4，而不是左 50%。原因是 @builtin(position) 在 fragment 阶段接近 render target / framebuffer 的物理像素坐标，不等于 Bevy window 的逻辑尺寸 1280 × 720。DPI 缩放会扩大实际 fragment 坐标范围。

如果要用真实物理宽度分割，查询 texture 尺寸：

let size = textureDimensions(source_texture);
let half_width = f32(size.x) * 0.5;

if in.position.x < half_width {
    return vec4<f32>(1.0, 0.0, 0.0, 1.0);
}
return vec4<f32>(0.0, 0.0, 1.0, 1.0);

如果要按归一化屏幕空间分割，直接用 uv：

if in.uv.x < 0.5 {
    return vec4<f32>(1.0, 0.0, 0.0, 1.0);
}
return vec4<f32>(0.0, 0.0, 1.0, 1.0);
接口用途本课验证
@group/@binding外部资源进入 shader变量名不重要，binding 数字必须存在
@locationstage 输入输出槽位输入缺失报错；输出错槽可能黑屏
@builtinGPU 管线内建语义position 是物理 framebuffer 坐标
