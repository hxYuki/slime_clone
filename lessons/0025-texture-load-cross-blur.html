Lesson 0025 · Texture Load Blur

textureLoad 与十字形 Blur

本课从 UV 采样切换到像素坐标采样：用 textureLoad 精确读取当前像素的左右/上下邻居，并用 mask 把模糊限制在聚光区域内。

本课胜利条件：能解释为什么 textureLoad 适合像素邻域操作，并能区分“单 pass 十字形 blur”和“真正 two-pass blur”。

1. textureSample 与 textureLoad 的分工

函数坐标是否使用 sampler适合场景
textureSample归一化 uv使用贴图采样、UV 扭曲、热浪、水波
textureLoad整数像素坐标不使用邻域采样、模糊、描边、边缘检测
textureLoad(texture, pixel_coord, mip_level) → texel color

2. 3 点横向模糊

最小横向 blur 只读取三个点：左、当前、右。

fn horizontal_blur3(source: texture_2d<f32>, pixel_pos: vec2<i32>, offset: i32) -> vec4<f32> {
    let size = vec2<i32>(textureDimensions(source));
    let center_pixel = clamp(pixel_pos, vec2<i32>(0), size - vec2<i32>(1));

    let left_pixel = clamp(center_pixel + vec2<i32>(-offset, 0), vec2<i32>(0), size - vec2<i32>(1));
    let right_pixel = clamp(center_pixel + vec2<i32>(offset, 0), vec2<i32>(0), size - vec2<i32>(1));

    let left_color = textureLoad(source, left_pixel, 0);
    let center_color = textureLoad(source, center_pixel, 0);
    let right_color = textureLoad(source, right_pixel, 0);

    return (left_color + center_color + right_color) / 3.0;
}

offset 是物理像素距离。它不是 UV，也不是逻辑窗口单位。

3. 用 mask 限制 blur 作用域

helper 只负责“如何模糊”；fragment 负责“在哪里应用”。

let position = vec2<i32>(in.position.xy);
let center_color = textureLoad(source_texture, position, 0);
let blur_color = horizontal_blur3(source_texture, position, 8);

var rect_color = mix(center_color, blur_color, spotlight_mask);

这个结构和颜色变暗一样，都是 mix(A, B, mask)。区别只是 B 现在是像素邻域计算出的模糊结果。

4. 纵向 blur 只是偏移方向变了

let top_pixel = center_pixel + vec2<i32>(0, -offset);
let bottom_pixel = center_pixel + vec2<i32>(0, offset);

横向和纵向 blur 的本质一样：都是从当前像素附近取样。方向由 offset 向量决定。

5. 保留的当前效果：十字形 blur

let offset = 12;
let v_blur = vertical_blur3(source_texture, position, offset);
let h_blur = horizontal_blur3(source_texture, position, offset);
let blur_color = (v_blur + h_blur) * 0.5;

var rect_color = mix(center_color, blur_color, spotlight_mask);

这会同时产生横向和纵向拖影。它是一个有用的 single-pass 近似效果。

命名建议：把它叫做 cross blur 或 single-pass cross blur。不要把它叫做 two-pass blur。

6. 为什么这不是 two-pass blur

在同一个 fragment shader 里：

let h = horizontal_blur3(source_texture, position, offset);
let v = vertical_blur3(source_texture, position, offset);

h 和 v 都读取原始 source_texture。它们不是先后处理关系。

single pass cross blur: source → horizontal(source) 和 vertical(source) → average

真正 two-pass blur 是：

pass 1: source → horizontal blurred texture
pass 2: horizontal blurred texture → vertical blurred final image
方案第二步读取什么覆盖范围
单 pass 横纵平均原图十字形方向样本
two-pass separable blur横向模糊后的中间图近似二维区域
