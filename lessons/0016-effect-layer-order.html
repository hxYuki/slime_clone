Lesson 0016 · Composition

控制效果层顺序

上一课的 bug 来自一行 mix 参数顺序。现在把 shader 写成一串命名效果层，让每个 mask 的影响范围都可读、可检查。

本课胜利条件：画面效果保持不变，但 fragment 代码从“不断修改 color”改成“命名中间层”，能直接读出每个效果影响哪里。

1. 先命名当前层，再进入下一层

sampled → rect_color → lit_color → ring_color → output

这不是为了性能，而是为了避免误读。每一层都回答两个问题：输入是哪一层？mask 是什么？输出叫什么？

层职责典型错误
rect_color纹理采样后，应用矩形变灰。后续还误以为它是原始纹理色。
lit_color用聚光 mask 在暗色与当前色之间混合。把 mix 两端写反。
ringed_color只在 ring * spotlight_mask 范围内叠加圆环。忘记 gate，圆环影响全屏。

2. 写出影响域

let ring_strength = ring * spotlight_mask;
let ring_target = vec4<f32>(lit_color.rgb + vec3<f32>(ring * 0.12), lit_color.a);
let ringed_color = mix(lit_color, ring_target, ring_strength);

ring 描述圆环形状；spotlight_mask 描述可见区域；两者相乘得到真正的影响域。先给它命名，就能降低顺序错误的概率。

3. 推荐的 fragment 结构

var rect_color = textureSample(screen_texture, texture_sampler, in.uv);

for (var i = 0u; i < material.rect_count; i = i + 1u) {
    let r = material.rects[i];
    if in.uv.x >= r.x && in.uv.x <= r.z && in.uv.y >= r.y && in.uv.y <= r.w {
        rect_color *= material.color;
        break;
    }
}

let dark_color = vec4<f32>(rect_color.rgb * 0.25, rect_color.a);
let wave = sin(material.elapsed_secs * 3.1415926) * 0.06;
let spotlight_mask = circular_mask(
    in.uv,
    material.spotlight_center,
    material.spotlight_radius + wave,
    material.spotlight_softness,
    material.ratio,
);
let lit_color = mix(dark_color, rect_color, spotlight_mask);

var delta = in.uv - material.spotlight_center;
delta.x *= material.ratio;
let d = length(delta);
let ring_phase = d * 32.0 - material.elapsed_secs * 6.0;
let ring_wave = sin(ring_phase) * 0.5 + 0.5;
let ring = ring_wave * ring_wave * ring_wave * ring_wave;

let ring_strength = ring * spotlight_mask;
let ring_target = vec4<f32>(lit_color.rgb + vec3<f32>(ring * 0.12), lit_color.a);
let ringed_color = mix(lit_color, ring_target, ring_strength);

return ringed_color;
判断规则：如果一行 mix 很难一眼读出“t=0 返回什么、t=1 返回什么”，就先把两端命名成 source 与 target，再写影响域。
mix(color, ring_color, t) 中 t = 0 返回什么？
