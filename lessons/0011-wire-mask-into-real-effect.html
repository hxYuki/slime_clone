Lesson 0011 · Tracer Bullet

把 Mask 接入真实效果

依赖模块已经进入 Bevy。现在沿一条完整路径传递聚光参数：Rust 值 → uniform buffer → WESL material → circular_mask → 最终颜色。

本课胜利条件：运行游戏时，屏幕中心保持原色，圆外变暗，边缘平滑且在 1280×720 下保持正圆。

1. 同步扩展 Uniform 契约

Rust

rect_count: u32,
spotlight_radius: f32,
spotlight_softness: f32,
aspect_ratio: f32,
spotlight_center: Vec2,
_padding: Vec2,

WESL

rect_count: u32,
spotlight_radius: f32,
spotlight_softness: f32,
aspect_ratio: f32,
spotlight_center: vec2<f32>,
_padding: vec2<f32>,

字段顺序完全对应。尾部按 u32 + 3×f32 + vec2 + vec2 组织，避免让两侧对 padding 作不同解释。

2. Rust 每帧提供实际参数

screen_material.spotlight_center = Vec2::splat(0.5);
screen_material.spotlight_radius = 0.3;
screen_material.spotlight_softness = 0.05;

screen_material.aspect_ratio = camera
    .physical_viewport_size()
    .filter(|size| size.y > 0)
    .map(|size| size.x as f32 / size.y as f32)
    .unwrap_or(1.0);

这仍是固定效果参数，但宽高比来自真实 viewport。先完成端到端路径，下一阶段再把中心、半径和软边抽成游戏组件。

3. Fragment 中组合颜色

let mask = circular_mask(
    in.uv,
    material.spotlight_center,
    material.spotlight_radius,
    material.spotlight_softness,
    material.aspect_ratio,
);

let dark = vec4<f32>(color.rgb * 0.25, color.a);
color = mix(dark, color, mask);
采样屏幕
已有矩形变换
生成圆形 mask
暗色与原色 mix
返回颜色
插入位置：把聚光代码放在现有矩形循环之后、return color 之前。这样它接收前一步已经处理过的颜色，再施加聚光效果。

实际编码：
  1. 在 Rust 与 WESL 的 RegionColorScreenMaterial 中按相同顺序替换尾部字段。
  2. 在 sync_greyout_regions_to_screen_material 的 camera 循环中写入中心、半径、软边和真实宽高比。
  3. 在 fragment 返回前调用 circular_mask 并用 mix 合成暗色与当前颜色。
