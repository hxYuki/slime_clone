Lesson 0021 · Sampling

Texture、Sampler、textureSample

上一课知道了三个 binding 从哪里来。现在要读懂它们如何合作：texture 是数据，sampler 是读取策略，UV 是地址，textureSample 是读取动作。

本课胜利条件：能预测把 textureSample(..., in.uv) 改成 textureSample(..., in.uv + offset) 时，画面会从哪里取色、边缘会怎样处理。

1. 三件东西各做一件事

对象不是职责
texture_2d<f32>不是函数一张二维颜色数据；采样后得到 vec4<f32>
sampler不是颜色规定越界时怎么处理、落在 texel 中间时怎么过滤
uv不是像素坐标归一化地址；当前全屏 pass 可把可见区域理解为 0..1
textureSample不是随机查找用 texture、sampler、uv 返回当前位置对应的颜色
color = textureSample(texture_data, read_policy, normalized_address)

2. 当前项目里的真实 sampler

FullscreenMaterial 使用：

let sampler = render_device.create_sampler(&SamplerDescriptor::default());

在当前依赖的 wgpu-types 29.0.3 中，默认 sampler 是：

策略默认值效果
address modeClampToEdgeUV 小于 0 或大于 1 时，夹到边缘颜色
mag/min filterNearest靠最近 texel 取值，偏像素风
mipmap filterNearest选择最近 mip level；当前全屏 source 通常不靠它制造效果

所以如果你采样 uv.x = 1.03，默认不会 wrap 到左侧，而是夹到右边缘。

3. 改 UV，就是改“从哪里取色”

let base = textureSample(screen_texture, texture_sampler, in.uv);
let shifted = textureSample(screen_texture, texture_sampler, in.uv + vec2<f32>(0.03, 0.0));

第二行在当前片元位置，读取“更右边一点”的屏幕颜色。结果显示到当前片元，所以视觉上通常像内容向左错位；右边缘会因为 ClampToEdge 被拉成边缘颜色。

4. 采样和效果组合的关系

之前的 mask、mix、ring 都是在“已经取到一个颜色”之后变换颜色。本课开始，你可以在取色这一步制造效果：

改什么效果类型例子
改颜色调色、灰化、发光color.rgb *= 0.25
改 mask区域、软边、优先级mix(dark, color, spotlight_mask)
改 UV扭曲、波纹、偏移、折射textureSample(texture, sampler, uv + distortion)
关键判断：如果效果像“画面被移动/扭曲/折射”，通常先看采样 UV；如果效果像“颜色被改变”，通常先看采样后的颜色变换。
