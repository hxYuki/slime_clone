Lesson 0015 · Time × Space

用时间与距离生成扩散圆环

上一课中，所有 fragment 共享同一个动画半径。本课让每个 fragment 用自己的 d 参与计算，做出从聚光中心向外扩散的圆环。

本课胜利条件：保留呼吸聚光，同时在聚光范围内看到一圈或多圈较淡的亮环向外扩散。

1. 标量场：每个 fragment 的 d 不同

var delta = in.uv - material.spotlight_center;
delta.x *= material.ratio;
let d = length(delta);

material.elapsed_secs 对整个 draw 相同；d 对每个 fragment 不同。把两者放进同一个公式，就能得到真正的逐像素动画。

phase = d × frequency − time × speed

当时间变大时，满足同一个相位的位置会移动到更大的 d，所以视觉上是向外扩散。

2. 把相位变成 0…1 的圆环强度

let ring_phase = d * 32.0 - material.elapsed_secs * 6.0;
let ring_wave = 0.5 + 0.5 * sin(ring_phase);
let ring = ring_wave * ring_wave * ring_wave * ring_wave;
项作用
d * 32.0空间频率：数值越大，同一距离内圆环越密。
time * 6.0运动速度：数值越大，圆环扩散越快。
ring_wave^4收窄亮区：让大部分位置接近 0，峰值附近保留亮环。

3. 只在聚光内叠加圆环

let original = color;
let darken_color = vec4<f32>(original.rgb * 0.25, original.a);

let base_radius =
    material.spotlight_radius + sin(material.elapsed_secs * 3.1415926) * 0.06;

let spotlight_mask = circular_mask(
    in.uv,
    material.spotlight_center,
    base_radius,
    material.spotlight_softness,
    material.ratio,
);

color = mix(darken_color, original, spotlight_mask);

let ring_color = vec4<f32>(color.rgb + vec3<f32>(ring * 0.25), color.a);
color = mix(color, ring_color, ring * spotlight_mask);

ring * spotlight_mask 是保护条件：圆环强度仍由距离和时间决定，但只在聚光可见区域内影响颜色。

函数式读法：这次管线是 uv → d → phase → ring mask → mix。区别在于 time 是共享输入，d 是每个 fragment 自己算出的输入。

实际编码：

  2. 在 fragment 中保留原来的矩形变灰逻辑。

  4. 先用 ring * spotlight_mask 叠加亮环；如果太强，把 0.25 降到 0.12。
