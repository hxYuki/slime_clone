Lesson 0020 · Attributes and Bindings

读懂 Attribute 与 Binding

这节开始从“效果公式”进入“shader 如何接到渲染器”。重点不是背语法，而是能回答：这个输入是谁给的，为什么编号必须对上？

本课胜利条件：能把当前 shader 的 @fragment、@location、@group、@binding 映射到 Bevy FullscreenMaterial 创建的 pipeline 和 bind group。

1. Attribute 是给编译器和渲染管线看的标记

Attribute约束对象在当前 shader 的含义
@fragment函数这个函数是 fragment stage 入口，会为片元计算输出颜色
@location(0)参数字段或返回值把 vertex 输出的 uv 接到 fragment 输入；把返回颜色写到第 0 个 color target
@builtin(position)参数字段使用 GPU/管线内置语义，不占普通 location
@group(0) @binding(n)全局资源变量声明 shader 要读取 bind group 0 里的第 n 个资源
 
struct FullscreenVertexOutput {
    @builtin(position) position: vec4<f32>,
    @location(0) uv: vec2<f32>,
}

@fragment
fn fragment(in: FullscreenVertexOutput) -> @location(0) vec4<f32> {
    return textureSample(screen_texture, texture_sampler, in.uv);
}

2. Binding 编号不是变量名决定的

shader 里的变量名 screen_texture 只是 shader 内部名称。GPU 真正匹配的是 group、binding、资源类型。

@group(0) @binding(0) var screen_texture: texture_2d<f32>;
@group(0) @binding(1) var texture_sampler: sampler;
@group(0) @binding(2) var<uniform> material: RegionColorScreenMaterial;

当前 Bevy fork 的 FullscreenMaterial 创建 layout 时，顺序是：

BindGroupLayoutEntries::sequential(
    ShaderStages::FRAGMENT,
    (
        texture_2d(...),      // binding 0
        sampler(...),         // binding 1
        uniform_buffer<T>(...), // binding 2
    ),
)

3. 资源值从哪里来

layout 只定义“槽位长什么样”。真正塞进槽位的是 prepare_bind_groups：

BindGroupEntries::sequential((
    texture,                 // binding 0: view_target 的 source texture
    &fullscreen_pipeline.sampler, // binding 1: Bevy 创建的 sampler
    settings_binding.clone(), // binding 2: ComponentUniforms<T>
))
Shader 声明Bevy 来源用途
screen_textureViewTarget 的 post-process source texture读取前面 pass 已经画好的屏幕颜色
texture_samplerRenderDevice::create_sampler告诉 GPU 如何按 UV 读取 texture
materialComponentUniforms<RegionColorScreenMaterial>读取 Rust 同步过来的效果参数

4. 最后在 render pass 里绑定

render_pass.set_bind_group(0, bind_group, &[settings_index.index()]);
render_pass.draw(0..3, 0..1);

set_bind_group(0, ...) 对应 shader 的 @group(0)。draw(0..3) 画一个全屏三角形；它的 vertex shader 产生 @location(0) uv，fragment 才能收到 in.uv。

阅读规则：看到 @group(g) @binding(b)，不要先猜变量名含义。先在 Rust pipeline / bind group layout 里找 group g 的 binding b 是什么类型、由谁填值。
