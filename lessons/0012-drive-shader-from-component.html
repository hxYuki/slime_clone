用组件驱动 Shader

上一课固定了聚光参数。本课把它们提升为 ECS 组件：游戏代码表达效果意图，同步系统把意图翻译成 uniform，fragment 继续执行同一个颜色函数。

本课胜利条件：不修改 WESL，只给相机挂一个组件，就能把聚光移动到左侧并缩小。

1. 分清两种数据

Game-side component

ScreenSpotlight 表达游戏想要的中心、半径和软边。它适合被关卡、动画或交互系统修改。

GPU transfer material

RegionColorScreenMaterial 镜像 uniform 字节布局。它是传输格式，不应成为玩法代码的主要接口。

2. 定义效果意图组件

#[derive(Component, Clone, Copy)]
pub struct ScreenSpotlight {
    pub center: Vec2,
    pub radius: f32,
    pub softness: f32,
}

impl Default for ScreenSpotlight {
    fn default() -> Self {
        Self {
            center: Vec2::splat(0.5),
            radius: 0.5,
            softness: 0.1,
        }
    }
}

这里没有 ratio：宽高比属于渲染目标，由同步系统从 camera 推导；它不是游戏设计参数。

3. 把组件映射为 Uniform

在 camera query 中加入 Option<&ScreenSpotlight>，并在循环解构中取得 spotlight：

let spotlight = spotlight.copied().unwrap_or_default();

screen_material.spotlight_center = spotlight.center;
screen_material.spotlight_radius = spotlight.radius;
screen_material.spotlight_softness = spotlight.softness;

Option 保留当前兼容行为：没有组件时使用上一课的默认值；有组件时由游戏覆盖。

4. 在相机上声明效果

ScreenSpotlight {
    center: Vec2::new(0.3, 0.5),
    radius: 0.22,
    softness: 0.04,
},

运行后，亮区应移动到屏幕左侧并明显缩小。WESL 没变，因为变化的是函数输入，不是函数定义。

实际编码：
  1. 在 region_color_screen_material.rs 定义公开的 ScreenSpotlight 组件和上述默认值。
  2. 扩展 camera query，把固定的中心、半径、软边替换为组件映射；保留现有 viewport ratio 计算。
  3. 在 main.rs 导入组件，并给相机添加示例参数 (0.3, 0.5)、0.22、0.04。
  4. 先预测画面，再运行验证。完成后告诉我“已完成”。
